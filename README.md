
# React Dashboard

A modern dashboard built with React and Vite.

## Features

- Dashboard
- Statistics cards
- Charts
- Task management
- Search
- Dark mode
- Responsive layout

## Installation

```bash
npm install
```

## Run

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Tech Stack

- React
- Vite
- JavaScript
- CSS
